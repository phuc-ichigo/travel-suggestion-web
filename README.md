# 🌏 Travel Suggestion Web
Web gợi ý địa điểm du lịch thông minh với AI

## Công nghệ
- Frontend: Bootstrap / Tailwind CSS + JavaScript
- Backend: PHP (MVC) + PDO
- Database: PostgreSQL
- AI: Claude API
- APIs: Google Maps, OpenWeatherMap, Booking

## Cấu trúc thư mục
- `app/Controllers` — Xử lý logic
- `app/Models` — Truy vấn database
- `app/Views` — Giao diện HTML
- `config` — Cấu hình DB, app
- `public` — Web root (index.php, css, js)
- `routes` — Định nghĩa URL
- `middleware` — Bảo mật XSS, CSRF
- `services` — Gọi AI, Weather, Booking API
- `database` — SQL migration
